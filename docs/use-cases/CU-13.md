# CU-13: Consultar movimientos de una cuenta

| Campo | Descripción |
|---|---|
| Actor | Usuario/Administrador |
| Objetivo | Consultar los movimientos registrados en una cuenta. |
| Precondiciones | El actor está autenticado y la cuenta existe. |
| Resultado esperado | El actor obtiene los movimientos de la cuenta respetando el orden de presentación asignado. |
| Requerimientos | Objetivo: RF-02, RF-03, RF-14. Reglas transversales: RF-01, RF-06, RF-07, RF-13, RF-27. |

## Flujo principal

- **CU-13.1:** El actor indica la cuenta cuyos movimientos desea consultar.
- **CU-13.2:** El sistema verifica que la cuenta pertenezca al usuario autenticado o que el actor sea administrador.
- **CU-13.3:** El sistema obtiene los movimientos de la cuenta y los entrega según el orden de presentación asignado, identificando si cada uno opera sobre el saldo de dinero o el saldo de deuda.

Finalización: se entrega el listado de movimientos.

## Flujos alternativos

### CU-13.A1: Movimientos de una transferencia

Desencadenante: paso **CU-13.1**, cuando el actor solicita consultar los movimientos de una transferencia entre cuentas.

- **CU-13.A1.1:** El actor identifica la transferencia que desea consultar.
- **CU-13.A1.2:** El sistema identifica las dos cuentas involucradas para comprobar los permisos sobre ambas.

Continuación: Continúa en **CU-13.2** para validar ambas cuentas; en **CU-13.3** entrega los dos movimientos de dinero de la transferencia.

## Flujos de excepción

### CU-13.E1: Acceso denegado

Desencadenante: paso **CU-13.2**, cuando el actor no está autenticado o no tiene permiso para acceder a la información solicitada.

- **CU-13.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-13.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.

## Consideraciones

- La búsqueda por fecha se desarrolla en [CU-17](CU-17.md) y el cambio del orden de presentación en [CU-18](CU-18.md).
- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
