# CU-03: Cerrar sesión

| Campo | Descripción |
|---|---|
| Actor | Usuario/Administrador |
| Objetivo | Finalizar el acceso autenticado actual. |
| Precondiciones | El actor está autenticado. |
| Resultado esperado | El acceso autenticado actual queda finalizado. |
| Requerimientos | Objetivo: RF-19. Reglas transversales: RF-13. |

## Flujo principal

- **CU-03.1:** El actor solicita cerrar su sesión.
- **CU-03.2:** El sistema finaliza el acceso autenticado actual.

Finalización: la sesión actual queda cerrada.

## Consideraciones

- No se define el cierre de otras sesiones del mismo usuario.
- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
