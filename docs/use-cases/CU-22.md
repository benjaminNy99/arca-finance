# CU-22: Consultar auditoría de una cuenta

| Campo | Descripción |
|---|---|
| Actor | Administrador |
| Objetivo | Consultar los registros de auditoría asociados a los movimientos de una cuenta. |
| Precondiciones | El administrador está autenticado y la cuenta existe. |
| Resultado esperado | Se entrega la auditoría de los movimientos de la cuenta con acceso de solo lectura. |
| Requerimientos | Objetivo: RF-03, RF-11. Reglas transversales: RF-01, RF-13. |

## Flujo principal

- **CU-22.1:** El administrador indica la cuenta cuya auditoría desea consultar.
- **CU-22.2:** El sistema valida que el actor esté autenticado como administrador.
- **CU-22.3:** El sistema obtiene los registros de auditoría de los movimientos de la cuenta.
- **CU-22.4:** El sistema entrega fecha y hora, responsable, cuenta, movimiento, acción, resultado y valores anteriores y posteriores cuando existan cambios.

Finalización: se entregan los registros de auditoría para su consulta.

## Flujos alternativos

### CU-22.A1: Auditoría de un movimiento

Desencadenante: paso **CU-22.1**, cuando el administrador solicita la auditoría de un movimiento concreto.

- **CU-22.A1.1:** El administrador indica el movimiento que desea consultar.
- **CU-22.A1.2:** El sistema identifica la cuenta a la que pertenece el movimiento.

Continuación: Continúa en **CU-22.2**, limitando la consulta de **CU-22.3** al movimiento indicado.

## Flujos de excepción

### CU-22.E1: Acceso denegado

Desencadenante: paso **CU-22.2**, cuando el actor no está autenticado como administrador.

- **CU-22.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-22.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.

## Consideraciones

- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
