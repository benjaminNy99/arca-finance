# CU-08: Consultar la información de una cuenta

| Campo | Descripción |
|---|---|
| Actor | Usuario/Administrador |
| Objetivo | Consultar la información de una cuenta autorizada. |
| Precondiciones | El actor está autenticado y la cuenta existe. |
| Resultado esperado | El actor obtiene la información de la cuenta autorizada. |
| Requerimientos | Objetivo: RF-02, RF-03. Reglas transversales: RF-01, RF-04, RF-05, RF-13, RF-27. |

## Flujo principal

- **CU-08.1:** El actor indica la cuenta cuya información desea consultar.
- **CU-08.2:** El sistema valida que la cuenta pertenezca al usuario autenticado.
- **CU-08.3:** El sistema entrega la información de la cuenta, incluidos su tipo y saldo de dinero y, para cuentas de deuda o tarjeta de crédito, su saldo de deuda por separado.

Finalización: se entrega la información de la cuenta.

## Flujos alternativos

### CU-08.A1: Consulta del administrador

Desencadenante: paso **CU-08.2**, cuando el actor autenticado es un administrador.

- **CU-08.A1.1:** El sistema permite consultar la cuenta aunque pertenezca a otro usuario, manteniendo el acceso de solo lectura.

Continuación: Continúa en el paso **CU-08.3**.

## Flujos de excepción

### CU-08.E1: Acceso denegado

Desencadenante: paso **CU-08.2**, cuando el actor no está autenticado o no tiene permiso para acceder a la información solicitada.

- **CU-08.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-08.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.

## Consideraciones

- Los movimientos, cuotas y auditoría asociados a la cuenta se desarrollan en sus respectivos casos de consulta.
- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
