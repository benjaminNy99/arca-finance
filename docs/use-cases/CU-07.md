# CU-07: Consultar cuentas propias

| Campo | Descripción |
|---|---|
| Actor | Usuario |
| Objetivo | Consultar sus cuentas financieras. |
| Precondiciones | El usuario está autenticado. |
| Resultado esperado | Se entregan únicamente las cuentas pertenecientes al usuario. |
| Requerimientos | Objetivo: RF-02, RF-22. Reglas transversales: RF-01, RF-04, RF-13. |

## Flujo principal

- **CU-07.1:** El usuario solicita consultar sus cuentas.
- **CU-07.2:** El sistema valida la autenticación y limita la consulta a las cuentas del usuario.
- **CU-07.3:** El sistema obtiene y entrega las cuentas del usuario.

Finalización: se entregan las cuentas propias que corresponden a la consulta.

## Flujos alternativos

### CU-07.A1: Consulta por tipo de cuenta

Desencadenante: paso **CU-07.1**, cuando el usuario solicita consultar sus cuentas de un tipo determinado.

- **CU-07.A1.1:** El usuario indica el tipo de cuenta que desea consultar.

Continuación: Continúa en **CU-07.2** y aplica ese tipo al obtener las cuentas en **CU-07.3**.

## Flujos de excepción

### CU-07.E1: Acceso denegado

Desencadenante: paso **CU-07.2**, cuando el actor no está autenticado o no tiene permiso para acceder a la información solicitada.

- **CU-07.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-07.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.

## Consideraciones

- La consulta por tipo de cuenta se desarrolla en el flujo CU-07.A1 y satisface RF-22.
- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
