# CU-21: Consultar cuotas pendientes e importes por mes

| Campo | Descripción |
|---|---|
| Actor | Usuario/Administrador |
| Objetivo | Conocer las cuotas pendientes y cuánto se debe pagar por ellas en cada mes. |
| Precondiciones | El actor está autenticado y la cuenta de deuda o tarjeta de crédito existe. |
| Resultado esperado | Se entregan las cuotas pendientes y sus importes totales agrupados por mes y año de pago. |
| Requerimientos | Objetivo: RF-17. Reglas transversales: RF-01, RF-02, RF-03, RF-09, RF-13, RF-08, RF-27. |

## Flujo principal

- **CU-21.1:** El actor indica una cuenta de deuda o tarjeta de crédito y solicita consultar sus cuotas pendientes e importes por mes.
- **CU-21.2:** El sistema valida que la cuenta pertenezca al usuario autenticado o que el actor sea administrador.
- **CU-21.3:** El sistema obtiene las cuotas pendientes y suma sus importes por mes y año de pago.
- **CU-21.4:** El sistema entrega las cuotas pendientes con sus importes y meses de pago, junto con el total correspondiente a cada mes.

Finalización: se entrega la información de pagos pendientes.

## Flujos alternativos

### CU-21.A1: Detalle de una cuota pendiente

Desencadenante: paso **CU-21.4**, cuando el actor solicita consultar el detalle de una de las cuotas entregadas.

- **CU-21.A1.1:** El actor indica la cuota pendiente cuyo detalle desea consultar.
- **CU-21.A1.2:** El sistema entrega la información de esa cuota, incluida la deuda o compra a la que pertenece, la fecha de adquisición, su importe y mes y año de pago.

Continuación: Finaliza el caso con el detalle de la cuota consultada.

## Flujos de excepción

### CU-21.E1: Acceso denegado

Desencadenante: paso **CU-21.2**, cuando el actor no está autenticado o no tiene permiso para acceder a la información solicitada.

- **CU-21.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-21.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.

## Consideraciones

- Las cuotas ya pagadas quedan excluidas de esta consulta. Los movimientos de adquisición y pago se consultan como movimientos de deuda o dinero, según corresponda.
- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
