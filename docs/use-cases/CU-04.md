# CU-04: Consultar perfil de usuario

| Campo | Descripción |
|---|---|
| Actor | Usuario |
| Objetivo | Consultar la información de su propio perfil. |
| Precondiciones | El usuario está autenticado. |
| Resultado esperado | El usuario obtiene la información de su perfil. |
| Requerimientos | Objetivo: RF-20. Reglas transversales: RF-13. |

## Flujo principal

- **CU-04.1:** El usuario solicita consultar su perfil.
- **CU-04.2:** El sistema valida que la consulta corresponda al usuario autenticado.
- **CU-04.3:** El sistema entrega la información del perfil.

Finalización: se entrega la información del perfil.

## Consideraciones

- Los campos que componen el perfil no están definidos. Este caso contempla su consulta.
- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
