# CU-05: Consultar cuentas de todos los usuarios

| Campo | Descripción |
|---|---|
| Actor | Administrador |
| Objetivo | Consultar las cuentas de todos los usuarios. |
| Precondiciones | El administrador está autenticado. |
| Resultado esperado | El administrador obtiene las cuentas de los usuarios con acceso de solo lectura. |
| Requerimientos | Objetivo: RF-03. Reglas transversales: RF-01, RF-13. |

## Flujo principal

- **CU-05.1:** El administrador solicita consultar las cuentas de todos los usuarios.
- **CU-05.2:** El sistema verifica que el actor esté autenticado como administrador.
- **CU-05.3:** El sistema entrega las cuentas con acceso de solo lectura.

Finalización: se entregan las cuentas para su consulta.

## Flujos de excepción

### CU-05.E1: Acceso denegado

Desencadenante: paso **CU-05.2**, cuando el actor no está autenticado como administrador.

- **CU-05.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-05.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.

## Consideraciones

- La consulta del detalle de una cuenta se desarrolla en [CU-08](CU-08.md).
- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
