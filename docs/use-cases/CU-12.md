# CU-12: Registrar entrada o salida de dinero

| Campo | Descripción |
|---|---|
| Actor | Usuario |
| Objetivo | Registrar un movimiento de dinero en una cuenta propia. |
| Precondiciones | El usuario está autenticado y la cuenta existe. |
| Resultado esperado | El movimiento queda registrado con su cuenta, importe, dirección, fecha y auditoría, y el saldo se actualiza. |
| Requerimientos | Objetivo: RF-06. Reglas transversales: RF-01, RF-02, RF-03, RF-05, RF-08, RF-11, RF-12, RF-13, RF-27. |

## Flujo principal

- **CU-12.1:** El usuario indica la cuenta y solicita registrar una entrada de dinero.
- **CU-12.2:** El sistema valida la autenticación, comprueba que la cuenta pertenezca al usuario y que el actor no actúe como administrador.
- **CU-12.3:** El usuario proporciona el importe y la fecha del movimiento.
- **CU-12.4:** El sistema registra el movimiento de dinero asociado a la cuenta y actualiza únicamente su saldo de dinero: suma el importe de una entrada o resta el de una salida, con la misma regla para todos los tipos de cuenta.
- **CU-12.5:** El sistema registra la auditoría del movimiento y el resultado de la operación en los logs.

Finalización: el movimiento y su auditoría quedan registrados.

## Flujos alternativos

### CU-12.A1: Salida de dinero

Desencadenante: paso **CU-12.1**, cuando el usuario desea registrar una salida de dinero.

- **CU-12.A1.1:** El usuario indica que el movimiento corresponde a una salida.

Continuación: Continúa en **CU-12.2**; en **CU-12.4** el sistema registra la dirección de salida.

## Flujos de excepción

### CU-12.E1: Acceso denegado

Desencadenante: paso **CU-12.2**, cuando el actor no está autenticado, actúa como administrador o no es propietario de la cuenta.

- **CU-12.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-12.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.

## Consideraciones

- Este caso registra movimientos sobre el saldo de dinero. La adquisición de deuda se desarrolla en [CU-24](CU-24.md), las compras a crédito en [CU-19](CU-19.md) y el pago de cuotas en [CU-20](CU-20.md).
- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
