# CU-14: Consultar detalle de un movimiento

| Campo | Descripción |
|---|---|
| Actor | Usuario/Administrador |
| Objetivo | Consultar la información de un movimiento registrado. |
| Precondiciones | El actor está autenticado y el movimiento existe. |
| Resultado esperado | El actor obtiene el detalle del movimiento autorizado. |
| Requerimientos | Objetivo: RF-02, RF-03. Reglas transversales: RF-01, RF-06, RF-12, RF-13, RF-27. |

## Flujo principal

- **CU-14.1:** El actor indica el movimiento que desea consultar.
- **CU-14.2:** El sistema identifica su cuenta y valida que pertenezca al usuario autenticado o que el actor sea administrador.
- **CU-14.3:** El sistema entrega la información del movimiento, incluidos cuenta, importe, fecha, clase de movimiento y efecto sobre el saldo de dinero o de deuda correspondiente.

Finalización: se entrega el detalle del movimiento.

## Flujos de excepción

### CU-14.E1: Acceso denegado

Desencadenante: paso **CU-14.2**, cuando el actor no está autenticado o no tiene permiso para acceder a la información solicitada.

- **CU-14.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-14.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.

## Consideraciones

- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
