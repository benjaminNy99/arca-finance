# CU-06: Crear cuenta financiera

| Campo | Descripción |
|---|---|
| Actor | Usuario |
| Objetivo | Registrar una cuenta financiera propia. |
| Precondiciones | El usuario está autenticado. |
| Resultado esperado | La cuenta queda registrada con propietario, tipo y saldo de dinero; las cuentas de deuda o tarjeta de crédito tienen además un saldo de deuda separado. |
| Requerimientos | Objetivo: RF-21. Reglas transversales: RF-01, RF-02, RF-03, RF-04, RF-05, RF-08, RF-09, RF-13, RF-27. |

## Flujo principal

- **CU-06.1:** El usuario solicita crear una cuenta financiera.
- **CU-06.2:** El sistema valida la autenticación del usuario y comprueba que no actúe como administrador.
- **CU-06.3:** El usuario proporciona el tipo y los datos de la cuenta.
- **CU-06.4:** El sistema registra la cuenta, la asocia al usuario propietario y conserva su tipo y saldo de dinero; si es de deuda o tarjeta de crédito, mantiene además su saldo de deuda por separado.

Finalización: la cuenta queda registrada a nombre del usuario.

## Flujos de excepción

### CU-06.E1: Acceso denegado

Desencadenante: paso **CU-06.2**, cuando el actor no está autenticado o actúa como administrador.

- **CU-06.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-06.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.
