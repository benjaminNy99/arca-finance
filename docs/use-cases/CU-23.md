# CU-23: Consultar logs de aplicación

| Campo | Descripción |
|---|---|
| Actor | Administrador |
| Objetivo | Consultar los eventos registrados por la aplicación. |
| Precondiciones | El administrador está autenticado. |
| Resultado esperado | El administrador obtiene los registros de aplicación disponibles para consulta. |
| Requerimientos | Objetivo: RF-26. Reglas transversales: RF-13. |

## Flujo principal

- **CU-23.1:** El administrador solicita consultar los logs de aplicación.
- **CU-23.2:** El sistema valida que el actor esté autenticado como administrador.
- **CU-23.3:** El sistema obtiene y entrega los eventos registrados con fecha y hora, severidad, evento, resultado y datos de correlación o diagnóstico cuando correspondan.

Finalización: se entregan los logs para su consulta.

## Flujos de excepción

### CU-23.E1: Acceso denegado

Desencadenante: paso **CU-23.2**, cuando el actor no está autenticado como administrador.

- **CU-23.E1.1:** El sistema deniega la operación sin revelar información de cuentas ajenas.
- **CU-23.E1.2:** El sistema registra el intento de acceso denegado en los logs.

Continuación: Finaliza el caso sin realizar la operación solicitada.

## Consideraciones

- Los logs excluyen contraseñas, tokens, credenciales y contenido financiero de cuentas, compras y movimientos.
- No están definidos los filtros, la retención ni el volumen de registros de esta consulta.
- Se aplican los [comportamientos compartidos de acceso, auditoría y logs](../use-cases.md#comportamientos-compartidos), según corresponda a la operación.
